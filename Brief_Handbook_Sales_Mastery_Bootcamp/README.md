# Brief — Handbook Digital Sales Mastery Bootcamp

Paket ini berisi semua yang dibutuhkan seorang AI agent (atau developer)
untuk membangun halaman handbook digital Sales Mastery Bootcamp.

## Cara memakainya

1. Buka `referensi/handbook-landing.html` di peramban terlebih dahulu.
   Inilah hasil akhir yang diharapkan.
2. Salin seluruh isi `01-PROMPT.md` ke AI agent Anda sebagai instruksi.
3. Lampirkan berkas pendukungnya: `02-DESIGN-SYSTEM.md`, `03-KONTEN.md`,
   `04-DATA.json`, folder `aset/`, dan `referensi/`.
4. Setelah agent selesai, periksa hasilnya memakai daftar centang di
   bagian akhir `01-PROMPT.md`.

## Isi paket

```
README.md                      berkas ini
01-PROMPT.md                   instruksi utama untuk AI agent
02-DESIGN-SYSTEM.md            warna, huruf, jarak, gaya komponen
03-KONTEN.md                   seluruh naskah, bab per bab
04-DATA.json                   rundown, trainer, denah kursi (terstruktur)
aset/                          lima foto siap pakai
referensi/handbook-landing.html  versi jadi sebagai acuan visual
```

## Tiga hal yang paling sering keliru dipahami

**Wi-Fi di bagian paling akhir itu disengaja.** Bukan kelalaian tata
letak. Peserta mencari informasi Wi-Fi, dan menempatkannya di ujung
membuat mereka melewati bagian keselamatan dan agenda lebih dahulu.
Karena itu tidak boleh ada menu lompat antar-bab.

**Lebar teks dikunci, bukan mengikuti lebar layar.** Di desktop, ruang
sisa dipakai untuk panel samping. Baris teks yang melebihi sekitar 700
piksel melelahkan untuk dibaca.

**Data yang belum ada jangan dikarang.** Nomor telepon, nama PIC, dan
menu makan masih kosong. Handbook ini memuat informasi keadaan darurat,
jadi nomor telepon contoh jauh lebih berbahaya daripada kolom kosong
yang jujur.
